## 二、三步上栏完整流程

### Step 0 — T9 数字按键输入

```
按键2 → 按键3 → 按键4 → ...
  2       23      234
```

- 用户点击九宫格数字键（2-9），每次追加一位
- 最长 20 位
- **500ms 防抖**：停止输入后自动触发 `autoTryResolve()`
- 点击「退格」：删除最后一位，重新自动解析
- 点击「清空」：所有状态归零（清空 T9 码、结果区、缓存）

---

### Step 1 — T9 码自动音节拆分 + 绿色实时候选

`autoTryResolve()` 在 500ms 防抖后自动执行：

#### 1A. 绿色实时候选（旁路直出）

```kotlin
val realtimeHits = engine.t9DirectQuery(t9, 50)  // T9 码直接前缀扫描 dict 表
```

- 输入 T9 数字 → 直接用 T9 码扫描 dict 词典
- 命中结果实时展示为**绿色卡片**，每个词下方显示**对应拼音**
- 标题栏格式：`实时  T9 "64426" 命中 12 个  ·  ni hao`
- 4 列网格，最多展示前 12 个
- 点击候选词 → `userPick` + 即时上屏（无需走后续步骤）

#### 1B. 拼音音节切分（DP 算法）

```kotlin
segmentT9IntoPinyinSyllables(t9)  // DP 分段
```

- DP 将 T9 数字串按音节边界切分
- 例：`"64426"` → `[SegmentOption("64", ["mi","ni"]), SegmentOption("426", ["gan","gao","han","hao"])]`
- 每段 T9 子码 → DFS 枚举字母组合 → 用 `PinyinDictionary.PINYIN_MAP` 过滤合法拼音
- **双层缓存**：`t9SegmentPinyinCache`（整串分段）+ `t9ValidPinyinsCache`（子码枚举），避免 O(3ⁿ) 重复计算

#### 1C. 拼音组合选择卡片

- **单段（1 个音节）**：直接展示拼音选项，点击即走引擎查询，无需确认按钮
- **多段（≥2 个音节）**：每节各选一个拼音 → 实时预览组合结果 → 确认后交引擎
  - 选中拼音：紫色高亮（`cPrimary`）
  - 未选中：灰蓝底色
  - 预览：`mi + gan → "migan"`，全部选定后变绿色

#### 1D. 手动查找（备选）

点击「查找」按钮 → `resolveT9()` 同样走分段+选拼音流程，且同样展示绿色实时候选卡

---

### Step 2 — 引擎 freeInput → 逐音节选字

`selectPinyin(py)` → `engine.freeInput(py, 200)`：

#### 2A. 引擎返回模式判定

| 返回结果 | 含义 | 处理 |
|----------|------|------|
| `bySyllable ≠ null` | 引擎成功拆分音节 | 进入逐音节选字卡片 |
| `bySyllable == null` 但有 `candidates` | 有候选词但未拆音节 | 展示热词分页卡片 |
| 都为空 | 完全未命中 | 自动生成拆分方案 |

#### 2B. 热词翻页卡片（`buildResultTopBar`）

- 绿色胶囊按钮 + 波纹反馈
- 4 列网格，每页 9 个热词
- 超出 9 个时显示 `◀ 上页 1/3 下页 ▶` 分页控件
- 点击直接上屏（`userPick` + toast 提示）

#### 2C. 逐音节选字卡片（`buildSylCard`）

每个音节显示一行：
```
音节 1: wu (T9: 98)
[五] [无] [物] [务]
[误] [屋] [武] [吴]
◀ 上页  1/3  下页 ▶
```

- 4 列网格展示候选字
- 每页 20 个候选字，自动分页
- 选中字：紫色高亮（`cPrimary` + `BOLD`）
- 未选中：灰蓝底色
- 点击候选字 → `pickWord(i, word)` → `userPick` + 保留翻页位置

#### 2D. 回退机制

引擎无法自动拆分音节时，两重回退：

1. **`buildManualSyllables(py)`**：`pinyinToT9(py)` → `engine.t9ToPinyins(t9)` 逐音节 → 每音节 `freeInput` 查询候选字
2. **`generatePinyinSplits(py)`**：递归拆分拼音字符串，每段用 `freeInput(part, 1)` 验证，结果按音节数排序

---

### Step 3 — 逐字组合 → 提交上屏

#### 3A. 底部预览栏

```
五经富   ← 全部选定后变绿色 (cSuccess)
```

- 实时显示当前选字组合
- 未选定的位置显示 `＿`
- 全部选定后文字变绿色，提示可以提交

#### 3B. 提交操作（`commitWord()`）

```kotlin
// 逐音节 userPick
for (st in syllableStates) {
    engine.userPick(st.selectedWord, st.t9Code, 200000)
}
// 组合词整体 userPick
engine.userPick(composed, t9, 200000)
// 刷新 freeInput 缓存（热词即时可见）
engine.freeInput(activePinyin, 200)
```

- 每个选中字分别调 `userPick`
- 组合词整体调 `userPick`
- 刷新 `freeInput` 使新热词即时生效
- 提交后清空选中状态（`selectedWord = null, page = 0`），保留候选列表

## 三、核心数据结构

### SegmentOption
```kotlin
data class SegmentOption(
    val t9Code: String,       // 该段 T9 子码，如 "64"
    val pinyins: List<String>  // 该段合法的拼音音节，如 ["mi", "ni"]
)
```

### T9SylState
```kotlin
data class T9SylState(
    val syllable: String,           // 拼音音节，如 "wu"
    val t9Code: String,             // 对应 T9 码，如 "98"
    val candidates: List<String>,   // 候选字列表
    val selectedWord: String?,      // 当前选中的字
    val page: Int = 0               // 分页位置 (每页 20)
)
```

## 四、缓存与优化

| 缓存 | 类型 | 作用 |
|------|------|------|
| `t9SegmentPinyinCache` | `Map<String, List<SegmentOption>>` | T9 整串→音节分段结果，DP 只算一次 |
| `t9ValidPinyinsCache` | `Map<String, List<String>>` | T9 子码→合法拼音列表，避免 DFS O(3ⁿ) 重复枚举 |
| `autoSearchHandler` | `Handler` | 500ms 防抖定时器，用户暂停输入后自动触发 |
| `quickHitsPage` | `Int` | 热词分页当前页码 |
| `comboSelections` | `MutableList<String?>` | 多段拼音组合中每段选中的拼音 |

## 五、引擎 API

| API | 调用位置 | 作用 |
|-----|----------|------|
| `engine.init(context)` | `onCreate` | 初始化引擎 |
| `engine.initDictManager(filesDir)` | `onCreate` | 初始化词典管理器 |
| `engine.t9DirectQuery(t9, limit)` | `autoTryResolve` / `resolveT9` | T9 码直接扫描 dict 词库 |
| `engine.freeInput(py, limit)` | `selectPinyin` / `buildManualSyllables` / `generatePinyinSplits` | 自由拼音输入，返回候选字+音节拆分 |
| `engine.t9ToPinyins(t9, fullMatch)` | `buildManualSyllables` | T9 码→拼音音节列表 |
| `engine.userPick(word, t9Code, amount)` | `realtimeChip` / `quickHitChip` / `pickWord` / `commitWord` | 热词自学习 |
| `engine.destroy()` | `onDestroy` | 释放引擎资源 |

## 七、交互规则速查

| 场景 | 操作 | 结果 |
|------|------|------|
| 输入 T9 数字 | 按键 2-9 | 追加到 T9 码，500ms 后自动解析 |
| 实时命中 | 绿色卡片点击候选词 | `userPick` + toast 上屏 |
| 单音节 T9 | 直接点拼音按钮 | 跳过组合选择，直接走引擎 |
| 多音节 T9 | 每节选一个拼音 → 确认 | 拼接后交引擎 freeInput |
| 逐音节选字 | 点击候选字 | 高亮选中，预览栏实时更新 |
| 候选字翻页 | 点击上页/下页 | 翻页保留当前选中字 |
| 提交上屏 | 全选后点击提交 | `userPick` × N + 刷新缓存 |
| 手动查找 | 点击查找按钮 | 同自动流程，额外显示实时命中卡 |
| 退格 | 点击退格 | 删除最后一位，重新自动解析 |
| 清空 | 点击清空 | 重置全部状态和缓存 |
