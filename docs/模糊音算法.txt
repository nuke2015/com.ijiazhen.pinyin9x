模糊音算法总结
================
[2026-07-18] 写入

一、什么是模糊音 (Fuzzy Pinyin)
--------------------------------
模糊音是中文输入法中处理发音相近、容易混淆的音节的机制。
例如：平舌z/翘舌zh、鼻音n/边音l、前后鼻音an/ang等。
开启模糊音后，输入"mi"也能匹配"ni"，因为它们发音相近且T9键盘上m/n同为6键。

二、双轨模糊匹配策略
---------------------

策略1：T9数字键位模糊 (Digit-Level)
-----------------------------------
每个T9数字位置尝试相邻按键，生成候选T9码再查词。
示例：
  输入T9码 "64" (mi/ni)
  → 第1位6的相邻键：5, 7, 8, 9
  → 第2位4的相邻键：2,3,5,6,7,8,9
  → 生成模糊码：54(li), 74(qi/pi/ri/si), 62(ma/na), 94(xi/yi/zi) ...
  → 用这些码去词库查候选词

策略2：拼音规则模糊 (Syllable-Level)
------------------------------------
T9码 → 反推所有可能拼音 → 应用模糊规则生成拼音变体 → 转回T9码查词。
示例：
  输入T9码 "64" → 反推拼音：mi, ni
  → 规则(n↔l): ni → li, mi→(m不在规则中,不变)
  → 规则(r↔l): (无r)
  → 模糊T9码：54(li), 74(ri)
  → 用这些码查候选词

三、标准模糊音规则表
---------------------

声母模糊 (Initial Consonants)：
  平翘舌不分：  z ↔ zh    c ↔ ch    s ↔ sh
  鼻边音不分：  n ↔ l
  h/f 不分：    h ↔ f
  r/l 不分：    r ↔ l

韵母模糊 (Finals / Vowel-Endings)：
  前后鼻音：   an ↔ ang    en ↔ eng    in ↔ ing
  ong混淆：    on ↔ ong
  展唇圆唇：   ian ↔ ie    uan ↔ ue

四、T9键盘天然模糊组
---------------------
T9键盘映射天然导致某些音节共用同一个T9码，无需额外规则：
  键2(abc)： ba/ca、ai/bi/ci、bo/an/ao ...
  键3(def)： di/ei、fa/da ...
  键4(ghi)： ge/he、go/ho ...
  键5(jkl)： jia/lia、jie/lie、ji/li、jian/lian ...
  键6(mno)： mi/ni、ma/na、min/nin、mo/no ...
  键7(pqrs)： pi/qi/si、pin/qin、ping/qing、pu/qu/su ...
  键8(tuv)： ta/tu、ti ...
  键9(wxyz)： xi/yi/zi、xin/yin、xing/ying、xia/zha ...

其中 mi/ni(键6)、ji/li(键5)、xi/yi(键9) 等是常见的模糊对。

五、应用场景
------------
1. 候选词查询 → 模糊音辅助推荐
2. 热词预测 → 同样叠加模糊匹配
3. 联想 → 基于上文的字模糊匹配
